# Sistema_gestion_transporte_urbano

## Descripción del Proyecto
**TecnoMovil Data** es una solución en **Java** diseñada para procesar y analizar volúmenes de registros de validación de pasajes en un sistema de transporte público urbano. El proyecto reemplaza la lógica imperativa tradicional mediante el uso del **paradigma de programación funcional**, garantizando un procesamiento de datos declarativo, escalable e inmutable.

## Funcionalidades Principales
* **Afluencia por Estación:** Conteo y agrupación de ingresos de pasajeros por estación.
* **Identificación de Horas Pico:** Determinación de los rangos horarios con mayor flujo de usuarios.
* **Rutas más Utilizadas:** Clasificación y ordenamiento de demanda por ruta.
* **Patrones de Movilidad por Usuario:** Rastreo cronológico de secuencias de viaje.
* **Tiempos Promedios:** Cálculo de duración de trayectos entre estaciones con `Duration`.
* **Detección de Sobrecarga:** Clasificación de rutas en estado crítico según umbrales de ocupación.

## Tecnologías y Conceptos Aplicados
* **Lenguaje:** Java 17+ (Java puro, sin frameworks externos).
* **Paradigma Funcional:** Java Streams API, Expresiones Lambda e Interfaces Funcionales.
* **Principios:** Inmutabilidad de datos, funciones puras y ausencia de efectos secundarios.
* **Control de Versiones:** Git y GitHub.
